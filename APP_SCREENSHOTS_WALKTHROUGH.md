# 📸 Application Visual Walkthrough & Screenshots

Below is a complete visual walkthrough of the main application screens, illustrating the pure white background, vibrant blue headers, solid black typography, and live data fed directly from the Aiven Cloud MySQL database.

---

## 1. Main Dashboard Screen (`DashboardScreenModern.kt`)
Features the vibrant blue header, profile photo container sync, priority alert cards, key metrics (50 Children, 20 Families, 50 Placements, 50 Applications), and action items.

![Main Dashboard Screen](screenshots/dashboard_screen.png)

---

## 2. Case Urgency Flags Screen (`CaseUrgencyFlagsScreen.kt`)
Opened by clicking the **Urgent Block** (`2 Urgent`). Features a pure white background, live urgency flags, risk count cards, and unsegmented continuous scrolling.

![Case Urgency Flags Screen](screenshots/urgency_flags_screen.png)

---

## 3. Risk Assessment Center Screen (`RiskAssessmentCenterScreen.kt`)
Opened by clicking the **At-Risk Block** (`10 At-Risk`). Displays risk evaluations, agency safety score gauge, and child welfare assessment logs.

![Risk Assessment Center Screen](screenshots/risk_assessment_screen.png)

---

## 4. Children Directory Screen (`ChildrenListScreen.kt`)
Displays live child profiles, DOB, gender, status, and county records synced from Aiven Cloud MySQL DB.

![Children Directory Screen](screenshots/children_list_screen.png)

---

## 5. Active Families Directory Screen (`FamiliesScreen.kt`)
Displays family contacts, primary/secondary names, phone numbers, and location details.

![Active Families Directory Screen](screenshots/families_screen.png)

---

## 6. App Settings & Biometric Configuration Screen (`SettingsScreen.kt`)
Contains system preferences, network IP pipeline settings, and the **Biometric Fast Login** switch toggle linked directly to the phone's hardware sensors.

![Settings & Biometrics Screen](screenshots/settings_screen.png)
